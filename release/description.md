# 星尘驿站 Stardust Relay

## 你是一件古老中转站的调度员。

每天都有迷途的飞船、AI、宇航员造访。
他们各自带着困境而来——
逻辑过载、情绪冻结、孤独循环……
而你的任务，是为他们调制一杯恰到好处的特饮。

---

## 游戏特色

**9 位性格迥异的访客**
冷静的深空探索AI、热情的货运飞行员、困在循环里的通讯中继站、冬眠太久忘记自己名字的宇航员、失去色彩感知的艺术AI——每一段相遇都有专属的故事。

还有量子观测AI「虚点」、远航船幼儿「漂泊者」、古老广播站AI「余响」、医疗舱AI「看护者」——每一位都等待被看见。

**8 张逻辑卡片**
循环 / 分流 / 增强 / 滤波 / 相位 / 震荡 / 锚定 / 半衰。用三张卡片调出正确参数。

**星际跃迁（Prestige 系统）**
第 30 天且累计治愈 15 次后可发起跃迁——积分归零，能源回满，但你的调度经验会永久刻入驿站的信号网络，带来更宽松的容差。

**渐进内容解锁**
游玩天数越久，解锁越多：完整背景故事、访客对话引用、关系网络图——每一次游玩都是深入这个宇宙的机会。

**压力模式**
跃迁后解锁的硬核模式。能源消耗×3，但积分×1.5、天数加速，适合追求极限的玩家。

**语音播报沉浸体验**
访客到来时的描述、治愈后的反馈，都有声音陪伴。

**程序化环境音乐**
Web Audio API 合成的深空 ambient 音乐，随着访客到来自动切换氛围。

**10 项成就**
从「初次治愈」到「金牌调度员」，记录每一次里程碑。

## 设计初衷

星尘驿站想探讨的是**「被需要的感觉」**。

货运飞船在无止境的航行中燃烧殆尽，AI在无尽的循环里忘记了自己想说什么，冬眠宇航员的意识锚定在虚无中——他们需要的不是拯救世界的大英雄，只是一杯温度刚好的热饮，和一句"我听见你了"。

而你，作为调度员，做的最重要的事不是算对参数，而是**让他们感到自己被看见了**。

---

## 操作

- **空格键**：扫描访客
- **点击卡片**：放置到调制槽
- **Enter**：开始调制
- **R**：重置调制槽
- **Esc**：切换休息模式

## 技术

纯 Web 技术栈，无需安装，打开即玩。
存档保存在浏览器本地，支持离线后重新打开继续游玩。
